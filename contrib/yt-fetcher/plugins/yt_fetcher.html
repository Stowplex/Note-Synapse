YTFetcher: YouTube Data Extractor

This application provides a tool to fetch a YouTube video's HTML page, extract the INNERTUBE_API_KEY, and fetch caption data using YouTube's Innertube API. It supports standard video links and YouTube live stream links.

Tool Playground: fetch_youtube_data

Enter a YouTube video URL or a direct video ID below to fetch its HTML, extract the API key, and retrieve caption data. This now supports YouTube live links too.
