# Hands-On: Git for Thoughts (Tree Chat)

Don't let a bad turn ruin a good conversation.

## The "Forking" Gesture
### Problem
You are debating architecture with the AI. It made a great point 5 messages ago, but then went down a rabbit hole about database drivers. You want to go back to that great point and explore a different direction.

### Walkthrough
1.  Scroll back to the **Message** where the AI made the good point.
2.  **Long Press** on that message bubble.
3.  Select **"Fork from here"** in the menu.
4.  **Result**: A new "Branch" is created.
    -   The old conversation is safe.
    -   You are now in a fresh timeline starting from that exact moment.

## Navigating the Tree
1.  Tap the **Tree Icon** (Branch symbol) in the top-right of the chat screen.
2.  You will see a graph visualization of your branches.
3.  **Green Node**: Your current location.
4.  **Blue Nodes**: Other branches.
5.  Tap any node to jump instantly to that version of reality.

## Hands-On: Context Pruning
1.  In the Tree View, long-press a node that contains huge output (like a 500-line log file).
2.  Select **"Mute Output"**.
3.  **Why?** This keeps the *fact* that the tool ran, but removes the *cost* of the tokens.
